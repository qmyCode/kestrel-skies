# Kestrel Skies

Fly the Kestrel K-7 prop plane over a living tropical archipelago in this pseudo-3D Canvas flight game. Three missions test your stick-and-rudder skills: **Ring Circuit** threads eight glowing hoops across the islands; **Volcano Mail Run** sends you around the smoking peak and demands a precision runway landing; **Storm Patrol** pits you against crosswinds and low fuel. Keyboard (WASD/Arrows for pitch & roll, Shift/Ctrl for throttle), mouse drag, or touch all fly the plane. Instruments and HUD give you altitude, airspeed, heading, fuel, and G-load at a glance.

## Run

```bash
# Start the static server
node serve.ts
# Open http://localhost:8080
```

Hand-in for make.fun:

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
